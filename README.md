# Watch Video for ChatGPT

Watch an Instagram Reel, find a clear reference frame, or request a playable download using your own connected browser.

## Install

1. [Download watch-video.zip](https://github.com/janpalacio29/watch-video/raw/refs/heads/main/watch-video.zip).
2. In ChatGPT, open **Plugins → Skills → Add skill → Upload from your computer** and select the ZIP. This requires an account with access to Skills.
3. In Work mode, type `@watch` and select the video skill under **Skills**, then paste the Instagram link. You can also send `/watch-video` as plain text. If you already shared the link in the conversation, just send `/watch-video`.

## Try it

- `/watch-video <Instagram link>` for a summary of the picture and available audio. Audio review requires a tool that can listen or transcribe.
- `/watch-video <Instagram link> find the clearest front-facing frame` for a character reference.
- `/watch-video <Instagram link> download` to request the video file.

Playback requires access to the post. Download availability depends on Instagram and the tools enabled in your ChatGPT session.
